# Bad Feminist｜英语精读项目

本项目仅服务于 Roxane Gay 的 _Bad Feminist_。

## 目标

1. 提升英文精读、词汇、句法与英文复述能力。
2. 准确理解并批判性分析书中女权主义相关论证。
3. 保留自己的真实判断并逐步形成原创文章。

## 文件说明

- `project-instructions.md`：复制到 ChatGPT Project Instructions。
- `progress.md`：阅读位置和归档进度。
- `vocabulary.md`：生词、词源、搭配和复习状态。
- `argument-map.md`：论证结构和跨篇关系。
- `reading-journal.md`：读者亲自表达的观点演变。
- `export-protocol.md`：增量合并规则。
- `chapters/`：按实际 EPUB 目录逐篇归档，不凭空编号。
- `essays/`：个人文章提纲与草稿。

## 使用方法

在网页创建 `Bad Feminist` Project，复制专属指令，上传原著及最新版 Markdown 快照。每篇文章使用一个主 Chat；按需输入“本节导出”“本章归档”。本地文件是正式版本，不会因为聊天导出而自动更新。

## 边界

请区别书中内容与作者的 TED 演讲《Confessions of a Bad Feminist》；只有经过原文核对的内容才能归入本书。
